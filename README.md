# OOTD 爆款台

独立本地女装换装视频审核页，汇总抖音、Instagram 和 TikTok 候选及已核验成片。

## 本地运行

需要 Python 3.9 或以上版本，无额外 Python 依赖。

```sh
python3 outputs/ootd-admin/server.py
```

打开 <http://127.0.0.1:8765/>。服务只监听本机地址。视频通过平台官方播放器嵌入，播放可用性可能因平台、登录状态或地区而变化。

## 数据与审核

- `outputs/ootd-monitor.json`：视频清单、核验证据、筛查规则、历史和每次运行记录。
- `outputs/ootd-admin/reviews.json`：用户选入、淘汰与复刻备注。
- `outputs/ootd-admin/index.html`：审核界面。
- `outputs/ootd-admin/server.py`：本地服务和审核记录保存接口。

筛查窗口为北京时间当天及此前 29 个自然日。抖音单条点赞须超过 1,000；Instagram 与 TikTok 须超过 400。仅日期、点赞、女装换装内容和实际播放均已核验的条目进入合格库。优先单套目标服饰，排除教程、纯颜值展示、男装和多造型合集。过期记录保留在历史中，用户淘汰记录不计入页面的有效库。

首批目标 200 条，每日目标新增 5 条；目标并不代表当前完成数量。实时数量和缺口以审核页及清单中的运行记录为准。

每日北京时间 09:00 的筛查由本机 Codex 自动化执行。这个仓库保存审核页与数据，克隆仓库不会自动建立该计划，也不会自动获取灰豚登录权限。数据更新后页面读取同一份清单；GitHub 同步需要单独提交并推送。

这是本机独立审核页，尚未接入业务后台、超管登录或 LibTV 制作流程。仓库不包含视频媒体文件、登录凭据、运行日志或本机服务启动配置。
